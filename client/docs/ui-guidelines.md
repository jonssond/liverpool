# Liverpool Discos - UI Guidelines

This document details the visual identity, styling conventions, typography, and color palette for the frontend interface of **Liverpool Discos**.

---

## 🎨 Visual Identity & Style Concept

> **Estilo**: A identidade visual combina a estética tátil e analógica do vinil clássico com um minimalismo moderno e sofisticado para e-commerce.

All screens should balance clean borders, generous spacing, and rich textures reminiscent of physical records, vintage sleeves, and editorial music magazines.

---

## 🖌️ Color Palette

The project uses a curated set of colors to create a vintage yet clean feel:

| Color Name | Hex Code | Role & Application |
| :--- | :--- | :--- |
| **Preto Vinil** | `#121212` | Base principal, fundos escuros, tipografia de destaque e elementos de contraste. |
| **Off-White Papel** | `#F4EFE6` | Fundo principal da loja, simulando o papel envelhecido das capas e encartes. |
| **Âmbar Quente** | `#D97724` | Cor de destaque (CTAs, botões de compra, selos e detalhes de iluminação). |
| **Verde Oliva Desbotado** | `#4A5844` | Cor secundária de apoio para categorias, tags, badges e embalagens. |
| **Terracota Suave** | `#B85D43` | Destaque complementar para banners promocionais e seleções de curadoria. |

---

## 🔤 Typography

The fonts selected reflect an editorial and interface division:

*   **Títulos & Elementos Editoriais**: `Georgia`, Serif. Used for headers, product titles, section names, and hero text.
*   **Interface, Menus & Informações**: `Century Gothic`, `Futura`, sans-serif. Used for navigation menus, table data, buttons, fields, forms, and secondary text.

## 🌐 Language Requirements

*   **UI Text**: All user-visible copy, text, alerts, placeholders, and charts must be presented in **Portuguese (pt-BR)**.
*   **Code**: Variables, classes, types, and database queries are in **English**.
